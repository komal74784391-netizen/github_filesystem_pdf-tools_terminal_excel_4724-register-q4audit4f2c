# TASR: Temperature-Annealed Sparse Routing

Unofficial community implementation of the preprint
**Temperature-Annealed Sparse Routing for Mixture-of-Experts**
(identifier **IR-2026-0417**).

The authors did not release an official repository for this work.  This
project is an independent reimplementation maintained by the community.  It
contains training scripts, configuration files and an evaluation harness for
the temperature-annealing gate schedule described in the preprint.
